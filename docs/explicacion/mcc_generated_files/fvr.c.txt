`FVR_Initialize()`: `FVRCON` = 0x81 = binario 1000 0001: FVREN = 1 (enciende la referencia) y ADFVR = 01 (ganancia 1× hacia el ADC: 1.024 V). El buffer de comparadores/DAC (CDAFVR) y el sensor de temperatura (TSEN) quedan apagados. El comentario de MCC lista cada campo.

`FVR_IsOutputReady()`: devuelve el bit FVRRDY, que el hardware pone a 1 cuando la referencia está estable (unos 60 µs después de encenderla, parámetro FVR04).
